App Mobile Mein Kaise Aaye Gi?

Play Store ya App Store ke bina seedha phone par install karein

Android Phones (Chrome Browser)
  1. Upar maujood "Download & Install App" button dabayein.
  2. Chrome browser screen par poochega: "Install Expense Tracker".
  3. Install par click karein. App direct aapke phone ki home screen par purple icon ke sath aa jaye gi.
Apple iPhones (Safari Browser)
  1. Safari mein link khol kar neeche center mein mojood Share button (⬆️) dabayein.
  2. Thoda neeche scroll karein aur "Add to Home Screen" par tap karein.
  3. Top right par Add dabayein, app bina Safari ke URL bar ke native app ban jaye gi.

Frequently Asked Questions

Kya is app ke liye internet zaroori hai?

Nahi! Yeh app 100% offline chalti hai. Agar aap Google se login karenge toh internet milte hi data cloud mein backup ho jaye ga.

Kya mera data safe hai?

Ji haan, sara data bank-grade encryption aur Supabase security ke zariye sirf aapke private account ke sath juda hota hai.

Phone badalne par mera hisab wapas aayega?

Bilkul. Naye phone mein sirf apna email ya Google login enter karein, aapke pichle saare records foran restore ho jayenge.
